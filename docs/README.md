## 🛠 Tech Stack Overview

- **Frontend**: Flutter (Dart), Material 3, Riverpod 3, GoRouter 18, Google Fonts (`Baloo 2` & `Nunito Sans`)
- **Audio**: `record` (Mic recording), `just_audio` (Playback)
- **Backend (Future)**: Firebase Authentication, Cloud Firestore, Supabase Storage
- **ML Backend (Future)**: FastAPI (Python), DTW + SSL Speech Embeddings, Naive Bayes / SVM / BiLSTM Sentiment Classifiers
